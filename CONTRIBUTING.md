\# Contributing to CampusNotes



Thank you for contributing to CampusNotes!



\## How to Contribute



1\. Fork the repository.

2\. Clone your fork to your local machine.

3\. Create a new feature branch.

4\. Make your changes.

5\. Test your changes.

6\. Commit your work using Conventional Commit messages.

7\. Push your branch to GitHub.

8\. Open a Pull Request.



\## Guidelines



\- Write clear and readable code.

\- Use meaningful file and variable names.

\- Keep documentation updated.

\- Avoid committing temporary files.

\- Provide a clear description of every Pull Request.



Thank you for helping improve CampusNotes!
